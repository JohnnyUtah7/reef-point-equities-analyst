# Unit economics

Write `artifacts/{TICKER}/04-research/unit_economics.md`.

From filings:

- Gross / contribution / EBITDA / EBIT margins (say D&A treatment)
- ROIC = NOPAT / invested capital (define IC)
- Capex vs D&A, SBC as % of sales, cash conversion
- Per-unit only if the 10-K actually counts units (MW, seats, stores)

SaaS (NDR, magic number, payback): **only** if disclosed. Do not import a SaaS kit onto a miner, a bank, or a retailer.

Label operating metrics (ARR, bookings) as non-GAAP.
